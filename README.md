## ✨ 核心优势
✅ **完整单词变形解析**：自动给出单词词性、音标、单复数、派生词（动词/名词/形容词/副词变体）、近义词、反义词、固定搭配，非常适合背单词备考
✅ **记录导出复习**：支持导出收藏、历史查询记录为 Word 文档，方便线下复盘背诵
✅ **自由切换AI模型**：可自行配置API，自主选择不同大模型（DeepSeek等）作为查询后端
✅ **英汉双向查询**：英文查释义变形、中文反向查对应英文词汇
✅ **本地保存查询历史与收藏**，界面简洁，轻量化桌面程序
